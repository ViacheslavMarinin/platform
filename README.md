# Мой маленький мир

Платформа для игр и приложений на **mlymir.ru**: общий вход, сохранения и общая валюта — уточки.

## Как устроено
- `mlymir.ru/` — витрина (этот репозиторий).
- `mlymir.ru/piko/` — «Пико и сокровища», отдельный сайт на Netlify (`brilliant-eclair-mar.netlify.app`, репозиторий `piko-treasures`). Подставляется под путь правилом в `netlify.toml`.
- `mlymir.ru/hamsters/` — «Хомячья мозаика», отдельный сайт на Netlify (`hamster33.netlify.app`, репозиторий `hamster-mosaic`).
- `mlymir.ru/sb/*` — прокси к Supabase (`zykuquspmtmfcaofebxx`), чтобы обходить блокировки.
- Вход общий, потому что все игры открываются с одного домена.

## Платформенный модуль
Игра подключает один скрипт:
```html
<script src="/sdk/v1.js" data-app="код-игры"></script>
```
| Что | Делает |
|---|---|
| `Platform.ready` | Promise: сессия проверена, внутри игрок или `null` |
| `Platform.user()` | `{ id, username }` или `null` |
| `Platform.onChange(fn)` | вызов при входе, выходе, смене игрока (в т.ч. в другой вкладке) |
| `Platform.login('login' \| 'reg')` | окно входа; для вошедшего — карточка с выходом |
| `Platform.logout()` | выход везде на этом устройстве |
| `Platform.load()` | прогресс этой игры из облака: `{ data, updated_at }` или `null` |
| `Platform.save(data)` | сохранить прогресс этой игры (таблица `saves`), вернёт время |
| `Platform.client` | клиент Supabase для своих таблиц игры |

Сессия лежит в `localStorage['mlymir-auth']` — общая для всех путей домена. Старая сессия Пико (`piko-auth`) переносится сама.
Логин превращается в служебный email `u<hex логина>@players.pikogame.app` — домен остался от Пико и не меняется, иначе старые аккаунты не войдут.
Supabase: локально напрямую, на сайте — через `/sb`.

## База
- `profiles` — игрок: логин (колонка `data` — старые сохранения Пико, больше не пишется).
- `apps` — игры платформы: код, название, путь.
- `saves` — прогресс: игрок + код игры → данные. Каждый видит и пишет только своё.
- `admins` — кто видит сводку (`mlymir.ru/admin/`); заполняется только SQL. Сводку отдаёт функция `platform_stats()`, остальным — ошибка forbidden.
- SQL лежит в `supabase/`, выполняется вручную в Supabase → SQL Editor.

## Структура
- `index.html` — витрина
- `admin/` — сводка по игрокам (только для админа)
- `sdk/v1.js` — платформенный модуль, `sdk/supabase.js` — библиотека Supabase
- `img/` — картинки (уточка, карточки игр)
- `fonts/` — Nunito, свои копии
- `netlify.toml` — перенаправления и кеш

## Добавить игру
1. Зарегистрировать игру в `apps` (SQL: `insert into apps (code, title, path) values (...)`).
1. Игра — отдельный сайт на Netlify. Все пути в ней относительные (`assets/x.png`, не `/assets/x.png`).
2. Подключить `/sdk/v1.js` с `data-app="<код>"`, прогресс — через `Platform.load/save`.
2. В `netlify.toml` добавить правило по образцу Пико: `/<игра>/*` → сайт игры. Ссылки на игру — всегда со слешем на конце.
3. Добавить карточку в `index.html`.

## Решения
- Пути, а не поддомены: сессия Supabase хранится в браузере для домена, и все игры видят одного игрока без общих cookie.
- Правила меняются только в этом репозитории, игры его не правят.

## Обновление
Commit + push в `main` → Netlify выкладывает автоматически.
